# Zig Data Structures

This is a simple learning project where I plan to explore creating simple data structures (linked list, binary tree, etc.) in Zig.

## Development environment

Open this repository in VS Code and run **Dev Containers: Reopen in Container** to use the Debian 13 development container. It installs Zig 0.17.0, Git, ZLS, and the `ziglang.vscode-zig` extension.
